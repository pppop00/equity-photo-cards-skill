# Five-card agent handoff

End state: five continuous PNGs plus schema-v5 slots and claim evidence. Palette and logo gates come first.

| Stage | Owner | Input | Output |
|---|---|---|---|
| A | Intake/normalization | Report folder | Canonical facts with metric and geography bases |
| A.5 | Logo production | Company identity + confirmed palette | Official logo path + Chinese short name |
| B | Content production | Normalized facts, `company_quality.json`, `country_lens.json`, `metric_basis.json` | Complete v5 slots + claim sidecar |
| C | Layout fill | Draft slots | Same facts and keys, copy fitted to fixed frames |
| D | Hardcode/logic audit | Final visible copy + sidecar | Specificity, mechanism, and attribution verdict |
| E | Validator 1 | HTML + slots + sidecar | Deterministic schema/geometry/logic verdict |
| F | Validator 2 | Same artifacts + authoritative sources | External fact-check verdict |
| G | Renderer | Validator-clean bundle | Five 2160×2700 PNGs |

Any copy change after stage F returns to E. No agent writes CFA Lens in schema v5. Archived CFA selector material is not invoked.

The content owner owns all five cards because the reader path must stay coherent. The layout agent may shorten but may not change epistemic type, source meaning, metric basis, country mechanism, or `未披露/不可比` reason. Validator 2 verifies governance, accounting quality, valuation time point, and country facts in addition to the financial numbers.

Exact filenames: `01_cover.png`, `02_porter.png`, `03_five_year_financials.png`, `04_company_quality.png`, `05_country_lens.png`.
