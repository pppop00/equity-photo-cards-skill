# Design Spec

This file is the strict publishing spec for all cards generated by this skill.

## Canvas

- Logical layout size (coordinates, validation, wrap widths): `1080 x 1350`
- Default PNG export from `generate_social_cards.py`: `2160 x 2700` (full render buffer; use CLI `--export-logical-size` for `1080 x 1350` downscale when needed)
- Background: `#FCFCFD`
- Export target: direct social post image (resize externally if a platform caps dimensions)
- No drop shadows, no dark background, no fake paper textures
## Typography

- Primary font: Arial family only
- Headings: bold Arial
- Body: regular Arial
- Body copy should use the enlarged mobile-readable baseline now used by the renderer and validator; increase readability first, but never at the cost of overflow or overlap
- Do not mix serif fonts
- Chinese and English should use the same family choice
- Letter spacing: `0`
- Do not add manual tracking or widened character spacing in titles
- Cover main title `每天学习一个公司`: 1 line only
- Company display name: use the short company name, for example `特斯拉`, not `特斯拉公司`

## Color System

Rendering colors depend on **`generate_social_cards.py --palette`** (`macaron` | `default` | `b` | `c`). The palette must be selected at P0 and passed explicitly to validation and export. **`macaron`** uses a warm cream canvas plus a dark header band. **`default`** and **`b`** use a light header strip. **`c`** uses a dark header bar. All four cards for one report **must** use the same palette or headers will not match; the palette is **not** stored in `card_slots.json`.

- Macaron background: `#FFF9F3`
- Primary text: `#24263A`
- Secondary text: `#5C5A6D`
- Divider/stroke: `#EEDFCC`
- Highlight panel: `#FFF3E6`
- Header background: `#141A2C`
- Peach accent: `#E07A3D`
- Pink accent: `#E44F67`
- Butter accent: `#F1B84B`
- Mint accent: `#25B879`
- Sky accent: `#4E8DEB`

## Global Layout

- Left top: `金融豹`
- Small brand subtitle below it: `FINANCE LEOPARD`
- Right top: page number only, for example `03`
- Horizontal divider below header
- Left bottom only: `公司名 | 日期`
- No right-top company monogram
- No footer brand copy
- Keep outer safe margin at `72px`
- Minimum vertical gap between major sections: `36px`
- Minimum gap between text blocks inside a section: `20px`
- Decorative circles must stay fully outside all text bounding boxes

## Copy Limits

- Cover title: 1 line
- Company name: 1 line
- Intro sentence: max 2 lines
- Metric cards: label 1 line, value 1 line; 3 or 4 tiles per row
- Card 1 yellow panel paragraph: `150` to `165` characters including punctuation and English, max 7 lines
- Card 1 yellow panel paragraph should be controlled by character budget first, not sentence count
- Bullet sections: max 4 bullets
- Each bullet: max 3 to 4 lines depending on column width
- Numbers, percentages, tickers, and English words must stay on one line and may not be split across line breaks
- Approved English proper nouns such as `FSD`, `Robotaxi`, and `Optimus` may be kept in English
- Commas, periods, semicolons, colons, enumeration commas, and equivalent English punctuation may not start a new line
- A line beginning with `，。；：、,.!?` or equivalent closing punctuation is an automatic validation failure
- Card 2 industry-structure paragraph: must be one complete summarized paragraph, max `113` characters
- Card 2 background bullets: exactly 4 bullets, each max `60` characters
- Card 2 Porter per-force evidence: exactly 5 entries (one per force), each `evidence` max `70` characters and a complete sentence
- Card 3 five-year arc narrative: max `140` characters, 2-3 complete sentences. For Chinese cards, write in Chinese-reader order: company/business shift → financial result → next validation variable.
- Card 3 inflection points: at least 3 entries, each max `56` characters, single complete sentence
- Card 3 legacy slots `recent_financial_highlights` and `revenue_explainer_points`: accepted for old slot files, not rendered in v4, and not an active copy target
- Card 4 cfa_lens.concept_intro: max `110` characters
- Card 4 cfa_lens.company_application: at least 3 bullets, each max `95` characters, complete sentences
- Card 4 cfa_lens.different_angle_insight: max `105` characters (AUTHORITY slot — `primary_quote` required in worker_notes)
- Card 4 cfa_lens.takeaway: max `48` characters
- Any font increase must be checked against section bounds, spacing, and overlap before export
- Never allow overlap, clipping, or hidden text

## Card-by-Card Structure

## Card 1 — Cover

- Title: `每天学习一个公司`
- Company name in red: renderer uses **`company_short_cn()`** — **short Chinese** name. **When `logo_asset_path` is set**, the name comes from **`card_slots.cover_company_name_cn`**, set by the **logo production agent**.
- Small English/ticker line below company name
- 3 or 4 metric cards in one row, sourced from `metrics_row` (format: `"Label|Value"` per entry)
- One rounded highlight panel titled `公司看点` carrying `company_focus_paragraph`
- Below `公司看点`, reserve a fixed small logo section directly on the card background

## Card 2 — Porter

- Top half is two panels side-by-side: left panel = `industry_paragraph` (industry structure synthesis); right panel = 4 `background_bullets`.
- Bottom half is one wide panel with the Porter five forces (label + score bar + per-force `evidence` text on one row). Order: 供应商、买方、新进入者、替代品、竞争强度.
- The evidence text sits beside its own bar so the reader sees score and reasoning together — this replaces the old left-side bullet column + right-side conclusion box.
- Each `porter_evidence.evidence` must be a complete sentence under 70 chars.

## Card 3 — 财务分析 (v4)

- Card title: **`财务分析`** at Y=198 (replaces v3's "五年故事 + 最近季度财务").
- Top panel (Y=270..630, `PANEL` cream fill): `five_year_arc.narrative` (2-3 sentences) + 3-4 `five_year_arc.inflection_points` as compact bullets. **v4 removed the in-panel "过去 5 年的故事" subheader** — the card title frames the section, so an extra subheader read as 公众号-cheap. Narrative starts at Y=306 (was 346 in v3). Chinese cards must use the company short name or `公司`, not a ticker-led sentence like `ALAB从...`.
- Middle band (Y=648..922): Sankey-style horizontal bars for `revenue / cogs / gross / op / net` from the renderer period (`financial_data.income_statement.current_year` with Sankey fallback). The title must name the period directly, e.g. `2025财年收入流`; never label an annual data pool as `最近季度`. Validator still fails if Card 3 would show `0.0` net income or `--` margins.
- Bottom panel (Y=940..1300, **frosted-glass `PANEL_GLASS` fill + `GLASS_STROKE` hairline outline**): 2×3 grid of `financial_metrics_panel` (6 CFA-importance metrics — slots 0..2 profitability/GREEN, 3..4 cash_flow/BLUE, 5 leverage/RED). Each cell shows: left-edge 5px colored accent strip, `label_cn` in small medium-weight `GLASS_LABEL`, and big bold `value` in the category accent color. If all six metrics share one `period_cn`, render it once as a panel-level caption (`2025财年口径`) and suppress per-cell period footers; render per-cell `period_cn` only when periods intentionally differ. The 6th leverage cell must be either `净债务/EBITDA | 0.5×` when net debt is positive, or `净现金 | 11.89亿` when the company is net-cash; never combine a ratio label with a net-cash value. Hairline `GLASS_DIVIDER` lines between columns and between rows give the panel a continuous-surface feel rather than 6 tile-cards. Value font auto-shrinks from 60 → 52 → 42 for long net-cash strings.
- v3 slots `recent_financial_highlights` and `revenue_explainer_points` are accepted by the loader for backward compatibility but no longer rendered.

## Card 4 — CFA lens

- Layout:
  - Top panel: concept name (large red serif) + 2-line `cfa_lens.concept_intro`.
  - Middle row: left mint panel with 3-4 `cfa_lens.company_application` bullets; right pink panel with `cfa_lens.different_angle_insight` body text.
  - Bottom band: cream panel with the one-line `cfa_lens.takeaway` (large serif red).
- This card teaches one CFA-syllabus concept through this specific company; the takeaway should read like a memorable rule, not a generic recap.
- The `different_angle_insight` is the AUTHORITY slot — it must reference a real quote (see `cfa-lens-selector-agent.md` § "Why-this-concept-fits").

## Logo Rules

- Card slots may provide optional `logo_asset_path`; the renderer uses only this explicit path and does not auto-discover local logos
- After palette confirmation, the production workflow must first check existing folder/slot logo assets; if absent, search the web for official brand / press-kit / IR-media logo references, then regenerate a clean transparent logo asset and point `logo_asset_path` at that file
- If no trustworthy official logo can be regenerated, omit the logo
- Never synthesize a fake logo from ticker letters in the header
- Never use screenshots, search-result thumbnails, or cropped webpage captures as the logo asset
- Exported raster logos must be large enough for a sharp downscale into the Card 1 slot (**≥840 px** wide for typical horizontal wordmarks at `LAYOUT_SCALE=2`; see `logo_asset_dimension_issues` in `generate_social_cards.py`). Do not submit upscaled favicons or tiny source images
- If a logo is used, keep it inside the content area and avoid decorative dominance
- After export, the output folder should retain only the actual logo file referenced by `logo_asset_path`; temporary logo source downloads and unused variants should be removed

## Prohibited Elements

- Dark backgrounds
- Decorative company monogram in the top right
- Mixed font families
- Overlapping text
- Tiny unreadable annotations
- Meta/internal copy about account strategy
- Extra footer text beyond `公司名 | 日期`
